- `all_values_for_livesplit.ct`: CheatEngine file containing all variables that can be used in LiveSplit

- `raw_var_list_for_livesplit.txt`: All variables that can be used in LiveSplit, written in LiveSplit syntax

- `full_level_end_scan.ct`: CheatEngine file that scans all addresses from `0x00503A78` -> `0` -> `100` -> `8` -> `0`.  Used to determine all level end sound memory addresses.
