# a descent into madness

Contains the beginning attempts to find a unique memory address, accessible from a pointer chain originating at a statically assigned address in the exe's base memory.

The victory screen is a spinning newspaper accompanied with a sound.

- `data/sprites/paperwin-h` is played on victory for hose levels
- `data/sprites/paperwin-r` is played on victory for rescue levels

- `win1.wav` is played on victory for hose levels
- `win2.wav` is played on victory for rescue levels
